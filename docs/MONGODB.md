# Microsite Builder — MongoDB Integration Guide

This document shows exactly how to store a `BuilderState` document in MongoDB with a **complete field-level validator**.

---

## Collection Design

Single collection: **`microsites`**. One document = one builder project. Embed the full `BuilderState` — never split nodes into separate documents.

---

## Document Structure

```
{
  _id:       ObjectId          — auto-generated by MongoDB
  projectId: String            — your app's project identifier (unique)
  userId:    String            — owner

  schema:       String         ─┐
  activePageId: String          │
  site:         Object          │  The full BuilderState
  theme:        Object          │
  pages:        Array           │
  nodes:        Object         ─┘

  createdAt: Date
  updatedAt: Date
}
```

```javascript
      bsonType: "object",
      required: ["projectId", "userId", "schema", "site", "theme", "pages", "activePageId", "nodes", "createdAt", "updatedAt"],

                bsonType: "object",
```

```javascript
async function saveMicrosite(projectId, userId, builderState) {
  const { schema, activePageId, site, theme, pages, nodes } = builderState;

  return Microsite.findOneAndUpdate(
    { projectId },
    { $set: { userId, schema, activePageId, site, theme, pages, nodes } },
    { upsert: true, new: true, runValidators: true }
  );
}
```

## Load

```javascript
async function loadMicrosite(projectId) {
  const doc = await Microsite.findOne({ projectId }).lean();
  if (!doc) return null;

  const { schema, activePageId, site, theme, pages, nodes } = doc;
  return { schema, activePageId, site, theme, pages, nodes };
}
```
